# VNK VPN — картинки для постов

Публичное хранилище картинок, которые бот @vnk_lab_bot прикладывает к рассылкам
(`photoUrl` в `POST /api/team/bot/post`). Telegram не может скачивать картинки
с vnklab.com (российский хостинг), поэтому они лежат здесь.

Ссылка на картинку:
`https://raw.githubusercontent.com/scamemusic/vnk-media/main/posts/<файл>`

Сюда — только то, что и так идёт в публичные посты.
